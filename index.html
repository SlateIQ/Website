How Slate-IQ Works

A five-step weekly workflow that transforms raw slate data into structured lineup decisions — documented in full, every single week.

01
Data Collection

Pull game logs, Vegas odds, and player projections for the full week's slate. No noise, just signal.

02
Model Execution

Apply Slate-IQ scoring. Rank by Pace → Usage → Minutes → Matchup. Identify core plays and leverage spots.

03
Ownership Analysis

Project field exposure. Find differentiation opportunities where value exceeds public consensus.

04
Lineup Construction

1 cash lineup (high-floor) + 4 GPP lineups (correlation + leverage + ceiling). Every pick documented.

05
Full Transparency Cycle

Lineups published pre-lock. Post-slate: full performance review, error analysis, model adjustments.
